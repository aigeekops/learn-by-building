# AI 学习路线后续课程补充计划

编排及归档日期：2026-11-08。更新：第一批3门基础课已制作21讲；按后续指令，第二批 HF Agents Course 与 FSDL 已制作16讲，见[第二批教学说明](application-courseware.md)。下文保留原规划的学习顺序，材料版本以实际课件为准。

恢复入口：[后续课程规划存档](course-expansion-archive.md)。

本计划用于 learn-by-building 的 AI 学习路线补全。先完成 CME 295、CS336、CS146S 三个专题，再启动新增课程制作。当前保持课程规划与静态页设计的分工，后续候选按学习缺口逐项引入。

学习主线是：编程与工程基础 → 数学、机器学习与深度学习 → 大模型原理 → 模型研发或 AI 软件工程 → 实践交付与评测。已有基础的人可以按先修自检进入相应分支；课程之间通过知识点互相连接。

## 当前三个专题的定位

| 专题 | 作用与学习产出 | 首批材料范围 |
| --- | --- | --- |
| [CME 295](https://cme295.stanford.edu/syllabus/) | 大模型原理主干。理解 Transformer、训练与微调、推理、RAG、Agent 和评测。 | 当前公开完整大纲为 2025 秋季九讲，按材料版本标注。 |
| [CS336](https://cs336.stanford.edu/) | 模型研发分支。亲手实现小语言模型，核算资源，并理解训练系统、数据与后训练。 | 使用已有第 1–16 讲中文精读；第 17 讲及嘉宾讲座另列扩展。 |
| [CS146S](https://themodernsoftware.dev/) | AI 软件工程分支。组织上下文、工具、Skills、规格、测试和评审，形成可复现的 Agent 开发流程。 | 使用已有 Fall 2026 课程地图，并逐项映射公开材料与本站原创练习。 |

CME 295 提供共同的模型认识。CS336 深入实现与训练，CS146S 深入软件开发与交付。进入 CS146S 需要相应编程和软件工程基础，不要求完整修完 CS336。

同一知识点保留一个基础入口，再链接不同深度的课程。例如 Token 在 CME 295 中解释含义，在 CS336 中进入分词实现与计算成本，在 CS146S 中进入上下文组织。

## 每讲的统一教学标准

1. 本讲问题与先修自检：用一个具体问题说明用途，并写清可交付的学习产出。
2. 通俗讲解：用同一个最小例子贯穿，先建立直觉，再进入公式与代码。
3. 逐步动画：支持播放、暂停、前进和后退，显示当前步骤、输入、中间状态与输出。
4. 代码运行演示：当前执行行、变量和画面对应。数值演示由真实计算驱动，固定执行轨迹明确标注。
5. 动手练习：先预测，再改参数或补代码，最后解释变化。
6. 独立验证：换一组输入、一个条件或一段代码，检查是否能独立复现和解释。
7. 深入精读：连接本站原稿、官方材料和完整实践，注明材料版本与适用范围。

浏览器承担小规模计算和可控流程演示。完整模型训练、GPU 性能实验与部署实践提供本地或云端任务。计算结果、模拟结果、真实运行日志分别呈现。

播放动画、通过一次测验或打开页面均不自动代表掌握，也不生成学习时长。学习记录保存用户实际提交的结果、解释和复现证据。

## 动画与练习的设计方向

| 内容 | 动画与代码演示 | 独立练习 |
| --- | --- | --- |
| Python 与工程工具 | 变量与调用栈、文件状态、管道数据流、Git 分支和调试位置 | 修改程序，解释输出；复现一次提交与错误恢复。 |
| 线性代数与概率 | 向量和矩阵变换、采样与分布、条件概率更新 | 先手算或预测，再改变输入并用代码核对。 |
| 机器学习与深度学习 | 决策边界、训练循环、前向与反向、参数与损失变化 | 修改数据或学习率，区分拟合、过拟合与泛化。 |
| 大模型与 Agent | Token、注意力、状态更新、工具调用、上下文和停止条件 | 复算一个中间结果，补一条失败处理路径。 |
| 交付与评测 | 数据、实验、评测、部署和监控之间的状态变化 | 复现一次失败，增加检查，再验证修复。 |
| 视觉与强化学习 | 卷积与特征图、网格世界、奖励与价值更新 | 换输入或环境条件，比较结果并说明局限。 |

优先制作与当前知识点直接相关的小例子。课程资料保留官方入口，本站增加原创中文导学、动画、算例与练习。

## 启动补全的条件

新增课程制作在当前三个专题的首批范围完成后启动。完成至少包含：

- 已明确覆盖的每讲都有讲解、动画、代码演示、练习和检验方法。
- 全站地图、专题栏目与单讲页面之间可以连续导航，并能回到相关先修。
- 计算和代码演示的结果可复算，手机与桌面布局经过检查。
- 练习反馈不会冒充真实训练、硬件结果或知识掌握。
- 官方材料、本站编排、简化模型与扩展内容清楚区分。

随后先补编程、工程工具与深度学习，再补 Agent 实作和工程交付，最后展开视觉与强化学习分支。具体制作数量与排期按前一批的完成情况决定。
