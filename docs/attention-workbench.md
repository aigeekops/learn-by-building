# Attention 逐格教学样板

入口：完整学习版 → CME 295 → 第 1 讲 → 动画与代码 → Attention。
课程、演示和草稿继续使用既有 `attention` ID。

以“我、学、AI”三个教学 token、给定的两维 Q/K/V 展开单头的一个位置：
输入 → 3 个点积格 → 3 个缩放格 → 3 个遮罩格 → 3 个 Softmax 权重格 → 2 个输出格，共 15 步。
点击阶段或结果格可以跳转，播放、前后单步、图形、当前算式、代码行和变量共享同一份计算轨迹。
输入在左侧标为金色，当前结果格用蓝框标出，未展开的结果显示点号。
遮罩使用 `null` 作为内部标记，界面显示 −∞；对应指数、权重和贡献严格为零。

参数区可选择 Query 位置、修改 K₂/V₂ 第一维，以及切换因果或双向模式。
修改参数保留正在检查的格子，第一次修改前的输入自动作为对照，也可以手动设置对照。
对照只保存在当前页面会话中；参数继续使用既有浏览器草稿。输入修改与播放均不新增学习时长、成果或完成状态。

三个验证案例使用实际计算结果：

- 只改 Key：在位置 2 将 K₂ 第一维从 1 改为 3。权重改变，但给定 Value 的对称性使输出仍为 `[1,1]`。
- 只改 Value：将 V₂ 第一维从 1 改为 3。权重不变，输出为约 `[2.006979687,1]`。
- 因果遮罩：在位置 1 改变未来位置的 K₂/V₂，当前输出不变；手动切换双向模式后再比较。

`web/ai-course-models.js` 负责计算，`web/attention-workbench.js` 只渲染已算出的轨迹；
完整学习版和原 AI 课件共用模型与渲染器。
课程主模块及合并目录的讲解同步修正了“改变 Key 必然改变输出”的旧表述。
这是原创教学算例，不包含分词、嵌入投影、多头拼接、训练或真实语言模型执行。

验证：`node --test tests/attention_workbench.test.cjs`。
独立全矩阵参考覆盖 Query 位置、遮罩、Key 和 Value 的 96 组组合，另外检查旧草稿默认值、逐格定位与参数对照。
公开构建仍使用 `scripts/build_learning_app.py`；AI 离线课件与静态站点也包含同一渲染器及样式。
