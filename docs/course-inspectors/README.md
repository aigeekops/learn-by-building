# 全课程逐格教学

26门现有课程分别由一个课程agent制作检查插件，课件、模型与学习记录继续使用原有身份。
课程范围以现有原创配套单元为准，不表示覆盖原大学课程的全部内容。
最终覆盖与可复算检查统计由 `coverage.json` 从当前课程配置及真实模型生成。

| 课程组 | 独立课程插件 |
| --- | --- |
| AI课程 | cme295、cs336、cs146s |
| 编程、数学与机器学习 | cs50p、tools、d2l、linear、probability、cs229 |
| 应用与交付 | hfagents、fsdl |
| 机器人共同基础 | mit2007、modern、pid、kalman、ros |
| 扩展课程 | cs234、bonn、manipulation、nav2、moveit、cs224r、underactuated、cs231n、arduino、lerobot |

每门课程的 `web/course-inspectors/<id>.js` 保留该领域的具体算式、输入、单位、假设和参数验证；
共享界面只负责选择格子、定位步骤、显示算式、准备对照和应用参数，不自行发明课程结论。

使用时，在原有“动画与代码”或机器人实验页，选择右侧结果格查看计算依据。
用原播放器单步、前后查看或回放已有步骤，也可以直接跳到某一步。
先选择一个验证案例、阅读预测和待修改条件，再点击“应用变化并核对”。
页面比较实际计算得到的结果；保持不变和发生变化的结论分别由各课程的验证函数检查。
手动修改参数会尽量保留当前步骤，第一次修改前的轨迹作为本次对照。
查看、播放、参数验证和默认输入恢复不改变学习完成状态或累计分钟。

静态几何与确定性计算展示计算检查，真实迭代展示实际存下的状态。
当前帧、历史快照和最终核对明确区分，未知或不适用的数值保留 `null` 并解释原因。
原Attention样板的专用矩阵读法保留；其他课程保留自己的图形和领域表达。

## 验证与构建

```sh
node scripts/check_course_inspectors.cjs --report docs/course-inspectors/coverage.json
node --test tests/course_inspector_*.test.cjs
python3 scripts/build_static.py
```

课程检查器对当前目录中的每个实际演示执行默认值和控制边界，逐帧检查格子、不可变性，
并实际执行每个案例的准备、应用和结果核对。专项测试补充独立算术、状态边界和未来值隔离。
正式构建要求26份课程插件齐全；部分完成的开发预览不能作为完整交付。

完整学习版、AI专题和机器人离线课件使用同一批检查插件。
源码与公开资产通过既有允许列表打包，不读取私人学习数据。
