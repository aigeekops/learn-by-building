## 使用与接入

正式交付入口为 `learning-map-courses-integrated.html`，与 `/Users/bytedance/Documents/pam/output/learning-unified-20261108/index.html` 同步为同一份完整页面。沿用全站学习地图和原有 `cs50p`、`tools`、`d2l` 三个课程身份；从地图选择课程。课程目录采用简短标题区、一个开始学习主操作和首屏可见的讲次列表，课程侧栏不重复目录，进入单讲后提供讲次导航。原有配套练习保留在课程目录下方，原有 Stanford 课件也保留。

可在文件 URL 后加 `?foundation=cs50p`、`?foundation=tools` 或 `?foundation=d2l` 直达课程；再加 `&lesson=cs50p-files` 等有效讲次 ID 可进入具体课。页面访问、动画播放和数值检查不自动创建个人路线、完成任务或增加时长。用户填写的练习保留在浏览器草稿中，可导出。

在项目目录执行：

```sh
python3 scripts/refresh_learning_delivery.py
# 检查 staging 后同步全部交付文件：
python3 scripts/refresh_learning_delivery.py --publish
node scripts/run_foundation_demo.cjs --list
node scripts/run_foundation_demo.cjs cs50p-functions '{"raw":7,"gain":3,"offset":-2}'
```

统一交付以最新未集成地图原稿为基础，接入全部课程与记录引擎。原稿先保存在项目快照中；发布前保存备份、检查目标哈希并原子替换，三处文件回读一致才算完成。单门课的接入脚本保留为内部增量工具，正式更新统一经过上述交付入口。学习记录、历史任务与回执不重写，新路线生成读取更新后的课程单元。

课程模块为 `config/foundation_cs50p.json`、`foundation_missing.json`、`foundation_d2l.json`；合并配置为生成的 `foundation_courses.json`。动画源代码在对应 `web/foundation-*.js` 中，命令行复算与页面使用相同实现。

## 动画可见性修复

用户反馈看不到动画后，复现了长讲解切换到动画仍保留内部滚动位置的问题：播放控件和画面可能已滚到可视区上方。修复后切入动画会定位到播放器，图示排在参数设置之前；地图、课程首页和每讲首屏均提供明确的播放入口。

新增21个专用SVG图示，与既有21个计算模型逐步对齐。Python展示变量、函数、分支、循环和文件；工程课展示目录、管道、环境集合及Git三份快照；深度学习展示张量格子、反向图、实际数据点与拟合直线、概率面积和注意力权重。未产生的计算结果保持等待状态。暂停时停止图示运动；减少动态效果偏好下仍可单步观察确定性的结果。

两组SVG场景新增22项测试，逐一核对161个默认步骤、控件边界与数值几何对应。浏览器另检查长讲解底部切入后播放器和画面均在可视区内，以及正常动画偏好下图形、步骤和代码同步推进、暂停停止运动。正常动画检查与减少动画模式下的布局检查分别执行。
