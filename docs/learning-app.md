## 运行与构建

在项目根目录执行：

```bash
python3 scripts/build_learning_app.py --serve
# http://127.0.0.1:8766/
```

修改源码后重新构建、刷新页面。可以使用 `--port 9000` 更换预览端口。去掉 `--serve` 只构建，或用 `--output <新目录>` 指定输出；脚本拒绝覆盖未知目录和源码。

构建包含：

- `index.html` 与 `learning-map-courses-integrated.html`：相同的完整入口，使用本地脚本、样式和图标。
- `assets/`：带内容哈希的运行资源。更新构建后会请求对应新文件。
- `standalone.html`：同一套内容的单文件离线版。
- `build-info.json`：课程讲数与文件校验值，不包含个人记录。

`python3 scripts/build_static.py` 会把此版本发布为公开站点的根 `index.html`（打开网站即进入课程地图与课件），并在 `learning/` 保留同内容副本以兼容既有链接与回归脚本；根产物与副本的 HTML 一致，`standalone.html` 保持单文件自包含。旧工作台页面不再发布。只有部署构建显式提供 Umami website id 时，根 `index.html` 才会注入统计脚本，副本与离线版始终不含外部脚本。Python 服务原有的 SQLite 工作台继续按既有方式运行，仅供本地开发。

## 源码归属

`web/learning-app/layout.html` 保存页面骨架；`workspace.js` 保存地图、导航与个人路线界面；`map.css`、`layout.css`、`page.css` 分别保存视觉样式；`icons.js` 提供本地图标；`data-engine.js` 保存个人路线与记录引擎的适配。`config/learning_app_catalog.json` 保存未来路线使用的公共课程目录。

构建从当前公共配置生成记录 schema 与课程数据，再复用 `refresh_learning_delivery.py` 及既有 AI、基础课、机器人课和动画布局接入模块。课程正文、模型和练习仍编辑各自的 `config/`、`web/` 模块；不编辑构建目录。构建不依赖 `.codex/visualizations/` 或项目之外的研究快照。

课程内页左侧只保留全站菜单，最顶部统一展示面包屑和已有个人路线选择。课程介绍、单元数、目录与开始学习入口放在正文；单讲的学习环节切换紧跟课题，不搬到全局顶栏，也不重复放返回按钮。各课程接入器更新标题前，先刷新共同页面框架，避免地图搜索框和旧的课程按钮残留。专注计时位于底部独立区域，不覆盖学习内容。

演示形式按知识点选择：CS50P 的变量函数示例展示调用栈、赋值前后和作用域快照；公差配合与电机负载选型使用交互计算。基础课不再循环闪烁圆点或滚动虚线，代码与命令示例默认单步查看。控制反馈、滤波、队列等有实际状态演变的内容继续保留动态过程。

CME 295 第1讲的 Attention 演示提供15步逐格计算：点选结果格查看输入与算式，前后单步或播放，并用 Key、Value、因果遮罩三个案例核对参数变化。详见 [Attention 教学样板](attention-workbench.md)。

这一标准已推广到26门现有课程：保留领域图示，按实际步骤展开可检查的结果格、数值代入和参数对照。各课程分别维护算式与验证条件，共享界面不自动认定学习完成。使用方式及覆盖清单见 [全课程逐格教学](course-inspectors/README.md)。

原型的 1–366 天计划只在新版构建的日期校验中适配；原有 Python 和工作台的 7/14 天行为保持不变。长计划使用同一版记录格式，备份恢复保留成果、真实时长及防重复保存回执。

## 个人路线排期

新版个人路线按分钟消耗每讲的预计学习量，不再固定每讲至少三天，也不按用户的周期反推或拉长工作量。一讲可跨日续学，同一天的剩余预算可接着安排下一讲；每天所有任务的分钟总和不超过每日投入。每第七天单独复盘，不计入新讲的学习量；所有选定课程排完后的余量显示为机动与补练。

`config/learning_app_catalog.json` 的 `study_load.lesson_minutes` 用稳定讲次 ID 保存各讲的编排估计；`core_minutes` 是未单列讲次的参考值（默认 180 分钟）。课程接入时保留 `lesson_id`，排序调整不会串用另一讲的估计。估计覆盖本站讲解、阅读、跟练和独立核对，不代表完整大学课程的官方课时或实测时长。

预览列出全部已选课程的完整排入、部分排入、未排入状态，以及每讲预计/已排分钟。起点之前和“只安排当前课程”排除的课程也保留在列表并说明原因。排入只表示预算覆盖；今日学习仍由当前课程和实际验收推进，不自动认定掌握。

排期只作用于新预览和新采用的个人路线；已有任务、成果、记录和计时不自动重排。原工作台的 Python 与 7/14 天排期不变。定向回归：`node --test tests/learning_app_schedule.test.cjs tests/learning_app_records.test.cjs tests/learning_app_focus.test.cjs`。

## 今日学习台的课程与任务范围

“当前课程”下拉框明确切换个人路线中的学习课程，保存成功后显示该课程的任务；“我的路线”中的“从这门课继续”使用相同逻辑。切换只保存课程位置，不重排既有任务，不改变成果、完成状态、学习时长或原专注计时的归属。保存失败时保留原课程。

任务范围按钮只筛选列表：“今日与待续”显示整条当前路线截至今天的未完成任务，不用未来任务填充空列表；“本课程任务”显示所选课程的全部安排；“整条路线”显示路线全部任务。后两项包括未来任务及已完成任务，不会切换当前课程或自动推进进度。尚未排期的课程显示对应空状态，不混入其他课程任务。

“整条路线”先展示各课程的概览，包含零任务课程与历史任务的兜底分组；按课程展开后每次加载20项，可一直加载到最后一项。各组任务数之和对应路线任务总数，不再截断前40项。今日和本课程列表也提供继续加载入口。未排期状态以已保存任务为准，查看概览不会为旧计划补写或重排任务。

新建路线沿用当前方向，可在表单中选择其他方向；调整旧路线会保留现有课程队列，并识别其方向或明确显示为自定义路线。方向改变时，默认名称跟随方向，用户填写的自定义名称保留。名称、方向、课程、日期或学习节奏改变后，旧预览即失效，需重新预览；迟到的预览结果不能覆盖新选择。采用时再次核对草稿与预览，顶部路线名称、课程列表和起点均来自本次采用的安排。

长路线与制定流程回归分别为 `node qa/learning_route_tasks.cjs`、`node qa/learning_route_selection.cjs`，使用各自的 `ROUTE_TASKS_BUILD`、`ROUTE_SELECTION_BUILD` 指向构建目录，仅操作隔离测试数据。

浏览器回归：构建后设置 `TODAY_BUILD` 为构建目录，执行 `node qa/learning_today.cjs`（需要 `PLAYWRIGHT_MODULE`；可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定本地测试浏览器）。覆盖 HTTP/离线、桌面/手机，以及任务日期、切课失败、路线隔离、刷新恢复与计时归属；仅使用独立测试数据。

页面默认铺满浏览器可用区域。导航底部沿用原工作台的 GitHub 仓库链接和 `web/author.json` 中的微信公众号信息；二维码从已有的核验资产嵌入，离线单文件无需联网。关闭作者配置或缺少二维码时，分别隐藏作者信息或回退为公众号名称搜索。

浏览器回归：先构建，再设置 `PLAYWRIGHT_MODULE` 执行 `node qa/learning_schedule.cjs`；可通过 `SCHEDULE_BUILD` 指定构建目录，`SCHEDULE_QA_OUTPUT` 指定截图和检查结果目录。覆盖 30/60/360 分钟的课程排入状态、预览只读、采用后的日预算，以及桌面/手机和联网资源/离线单文件四种组合。

## 个人数据

记录保存在浏览器 IndexedDB，参数、填写和界面偏好保存在浏览器本地。保留原有数据库和草稿命名方式；页面访问、动画播放和数值检查不自动完成任务或增加学习分钟。更换浏览器、站点地址或目录时，先在原入口导出备份，再到新入口预览和导入；构建过程不读取或迁移个人数据库。

专注计时在地图和课件页恢复时也会加载原任务，结束前重新核对任务与保存回执。待保存的结果会回填表单，失败后修改再提交仍沿用同一次计时标识；已经保存的结果不重复累计。原任务找不到时保留计时，并提供下载和需明确确认的清除入口。

## 验证

```bash
python3 -m unittest discover -s tests -v
node --test tests/*.test.cjs
```

新增检查覆盖：独立源码构建、文件完整性、重复构建一致、拒绝覆盖用户目录，以及 366 天计划的末日、成果和幂等回执在备份恢复后的保留。浏览器复核课程导航、动画与响应式布局。PyTorch、ROS/Gazebo 的真实环境运行状态沿用各课程已注明的验证边界；网页构建和浏览器检查不替代这些实验。

计时恢复与失败重试的定向回归：`node --test tests/learning_app_focus.test.cjs tests/learning_app_records.test.cjs`，覆盖任务尚未加载、丢失回执、表单修改、原任务删除，以及旧版计时迁移。

## 浏览器导航

地图、课程目录、具体讲次、学习环节和全站页面均支持浏览器后退、前进和刷新恢复。地址中的 `#learn/` 只包含公开页面、课程、讲次及环节 ID；个人路线、草稿、记录和计时不写入地址。原有 `application` / `foundation` 查询链接仍可用；同时存在新的位置 hash 时，以 hash 为准，避免刷新跳回旧入口。

切换历史位置会关闭临时窗口，不触发学习完成、活动记录或时长保存；课件草稿和专注计时继续使用原有浏览器存储。重复点击同一页面或学习环节不增加历史条目。地图展开状态只保存在当前历史条目的少量界面状态中。

导航回归：先构建，再设置 `NAVIGATION_BUILD` 为构建目录，执行 `node qa/learning_navigation.cjs`（需要 `PLAYWRIGHT_MODULE`）。脚本使用独立浏览器上下文和临时 HTTP 服务，覆盖本地资源入口及离线单文件的桌面、手机视口，不读取个人浏览器数据。
